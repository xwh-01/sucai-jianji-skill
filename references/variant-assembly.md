# 连续版与冷开回接版组装

## 共同输入

对三个已锁定的 `opening_window` 分别执行本文件流程。每个开头始终生成连续版；通过可行性判断时再生成冷开回接版。两版存在时共享同一个窗口和源视频事实，但独立选择结束位置。参考目标时长约 150 秒，允许为了完整台词、动作和尾钩自然浮动。

## 开头剧情标题

本节仅在主流程第 6 阶段执行；阅读到本节不代表应先生成标题。第 4 阶段先执行下文连续版、可行性、第二段比较及尾钩规划。

冷开回接版存在时，与连续版共享同一条头顶字幕及视觉设计。字幕只能在开头窗口、所有实际生成版本的入口、恢复点、尾钩和剧情区间锁定后生成。选段阶段必须假定头顶字幕不存在，不得用尚未生成的字幕解释人物关系、降低理解门槛或证明某个更短入口成立。字幕生成后也不得反向修改任何 `ranges`。

生成前先列出观众能够感知的信息。对白，以及剧本明确要求呈现的动作、表情、道具、特效、环境声、画面文字和视听内容，可以在纯剧本阶段作为预计的观众信息；人物小传、剧情梗概、场景标题、角色标签、内心活动、作者解释和没有通过对白或画面外化的身份、关系与动机不属于观众信息。纯剧本证据必须标为待 ASR 或视频核实，不能冒充已经检查过真实成片。

头顶字幕自动选择一个主要作用：

- `necessary_context`：成片仍缺少一个理解开头必需的身份、关系或处境事实时，用最短准确文案补上该事实；不补完整背景，不承担第二段剪辑功能。
- `retention_hook`：现有台词与画面已经足够理解时，使用准确但不提前兑现的强承诺，突出即将出现的反转、危险、欲望或身份变化，诱导观众继续观看。

两种模式都自动生成唯一一组三行英文，不输出候选，也不等待人工选稿。文案必须来自已锁定剧情的真实事实，不复述当前对白，不捏造关系，不把开头内部的第二次揭示提前说完；前两行建立必要语境或悬念，第三行集中主要承诺。只有剧本而没有 ASR 与视频时，这三行只能作为 `provisional_headline` 草案输出，不得标记为最终标题或用于证明开头能够理解。

文案确定后再自动完成视觉设计。抽取开头第 `0.0`、`1.0`、`2.0` 和 `3.0` 秒附近的代表帧，综合顶部区域的明暗、主色、人物位置与原片文字选择配色和断句。保持顶部居中、无矩形底框、轻黑描边；前两行使用同一基础色，第三行使用单一强调色。基础色优先高亮中性色，强调色从暖金、警示红、冷青或与剧情气质相符的高对比颜色中选择；不得只因模板默认而固定使用黄色，也不得使用与背景接近或过多的颜色。

自动检查四个代表帧上的可读性、人物遮挡、画面边界和原片字幕冲突。不通过时依次调整颜色、断句和字号，仍无法通过时才使用白色基础字、暖黄色强调字和轻黑描边作为回退。标题完整显示 `3.0` 秒，在第 `3.0-4.0` 秒线性淡出，之后不再出现。

## 连续版

从 `opening_window.start` 开始，按源剧情顺序跨集向后延续：

```text
开头窗口
-> 当前事件完成或升级
-> 后续连续剧情
-> 适合停下的尾钩
```

不要在第一版删除或替换中间剧情。跨集仅代表文件边界，不代表新剧情板块。遇到源片片尾黑场、片头重复或技术性静帧时记录为边界清理项。

## 冷开回接可行性

连续版路径确定后、生成冷开回接版之前，针对已经锁定的开头执行一次独立判断。该判断只能决定是否生成冷开回接版，不能替换开头、缩短开头窗口或重新竞争开头名额。

必须同时满足：

1. `prior_context_exists`：用户允许范围内存在位于 `opening_window.start` 之前的真实剧情；开头已经位于允许范围最前端时直接不成立。
2. `causal_context_exists`：前情中存在观众可感知的直接原因、人物动机或必要关系，能够回答开头留下的具体问题；只有无关背景或重复信息时不成立。
3. `natural_entry_exists`：至少存在一个不从半句话、半个动作或情绪中段进入的自然入口，并能形成可连续观看的剧情链；只能取开头前几秒解释时不成立。
4. `clean_catchup_exists`：第二段能够按时间顺序自然追上开头，冷开结尾存在可独立重复的最后一句或最后一个动作，且重复后能从完整动作或台词干净接入新剧情。
5. `adds_viewing_value`：相比连续版，回接确实增加必要信息、情绪积累、强事件推进或新的留存价值；只是改变顺序、重复同一信息或让观看更绕时不成立。

结果记录为 `cold_open_eligibility`：

- `eligible`：五项全部成立，继续生成冷开回接版。
- `no_prior_context`：允许范围内没有开头之前的真实剧情。
- `no_causal_context`：存在更早剧情，但与开头问题没有必要因果联系。
- `no_natural_entry`：找不到能够独立顺播的自然入口。
- `no_clean_catchup`：无法自然追上，找不到可独立重复的冷开结尾，或重复后没有干净的新剧情恢复点。
- `no_added_value`：技术上能够回接，但没有比连续版增加实际观看价值。

不成立时只生成连续版，并在报告中写明失败项和证据。不得为了补齐数量硬取几秒素材、使用无关前情、重播整个开头、伪造因果或更换已经锁定的开头。

## 冷开回接版

只有 `cold_open_eligibility.eligible` 为 `true` 时才执行本节。

固定结构：

```text
开头窗口
-> 0.8 秒静止末帧
-> 2.0 秒黑屏问题字幕卡
-> 1.0 秒快速倒放完整前情段，落回其第一帧
-> 从多个候选中选出的最佳自然入口
-> 按时间顺序追上开头
-> 重复冷开的最后一句或最后一个动作
-> 从 opening_window.end 接入新剧情
-> 爆点后的第一个新悬疑点
```

### 必要因果链与第二段入口

黑屏后的回接版第二段不是解释补丁，而是一段能够独立顺畅观看、自然回到开头并在其后建立新悬念的连续剧情。不得先猜时长。先通读授权范围起点至开头之前的完整正文，按原剧情顺序登记相关事件及自然入口，覆盖关系或处境建立、冲突起源、直接触发三个层次；保留有观众信息、情绪积累或反转价值的前情，不能因为删除后仍能理解当前动作就提前排除。再写开头留下的核心问题，反推直接原因、人物动机和必要关系，形成作为理解门槛的 `causal_chain`。问题和最小因果链不得缩小前情搜索范围。

把搜索记录保存为 `entry_search`：明确实际检查的起止文字锚点和证据来源，按时间顺序列出相关事件。每个事件都必须进入正式入口比较，或记录不适合作为入口的具体原因；不能静默遗漏更早的事件。不存在的叙事层次明确写原因；同一事件承担多个层次时合并，不能伪造候选凑数。授权范围内正文缺失时标记未完成，不得宣称查全。

对因果链中的每个节点分开记录证据来源：

- `dialogue_evidence`：剧本预计或实际 ASR 确认的可听对白，并记录核实状态。
- `visual_evidence`：剧本明确会呈现的动作、表情、道具、特效、环境声、画面文字或其他视听内容；纯剧本阶段可用于候选判断，但必须标为待视频核实。
- `excluded_script_information`：人物小传、隐藏身份、内心活动、作者解释，以及没有通过对白或可见画面外化的身份、关系和动机；明确记录且不得用于通过理解检查。

任何关键节点只由 `excluded_script_information` 支撑时，必须视为观众信息缺口，不能用它证明候选成立。

从上述事件清单生成自然入口候选，包括当前行动起点、冲突起点和关系或情绪变化起点，不以最早必要因果节点为搜索边界。保留最晚完整入口，并纳入真实存在的更早叙事入口；同一场景相邻几帧或相邻台词的切法不能替代不同叙事层次的比较。若确实只有一个入口，必须由完整搜索记录说明其他层次不存在、合并或不适用的原因，不硬凑两个。对每个候选从头顺播到开头，在全部通过因果理解门槛的候选中，比较观众新增信息、连续剧情、强事件密度、情绪积累和回接体验。最晚入口和最集中的入口都不享有默认优先级。

自然入口通常位于：

- 新场景或新行动开始。
- 人物目标、期待或关系重新建立。
- 导致开头事件的情绪开始积累。
- 一次完整冲突、暧昧或调查过程的起点。

第二段应根据当前事件补充真正有用的信息：

- 人物为何处于当前关系或情绪状态。
- 威胁、冲突或欲望为何出现。
- 某人为什么来到现场或采取当前行为。
- 后续对白依赖且无法自然推断的事实。

以下情况不能仅因为“信息已经够懂”而选作入口：

- 只剩开头前一两句解释性对白。
- 从对话、动作或情绪的中间进入。
- 播放几秒就撞回开头，形成明显倒带感。
- 只交代事实，没有让期待、冲突或情绪成立。

短回接只有在它本身就是完整、自然的微事件时才成立。必要时每次向前扩展一个完整场景、行动或情绪单元，然后重新顺播检查；不为了完整介绍所有人物而机械返回第一集，也不补充与开头因果无关的背景。

### 自动顺播检查

入口资格检查：选中入口前必须从候选起点按原顺序模拟观看，并同时满足：

- 第二段内容无需依赖未展示的半句、半个动作或场外事实才能成立。
- 必要因果链中的每个节点都在第二段中出现，且先后关系可理解。
- 第二段形成“处境或关系建立 -> 冲突、欲望或目标出现 -> 一次或多次明显变化、升级或反转 -> 自然逼近开头”的连续剧情链；允许包含多个彼此有因果连接的强事件。
- 回到开头前已经形成情绪投入，不是全程静态解释或信息摘要。
- 从入口到开头持续出现能够维持观看的具体事件或新信息；不能只做到结构闭合，却让中间观看过程平淡或信息单薄。
- 追上开头后只重复冷开的最后一句或最后一个动作一次，并能从完整动作或台词接入新剧情。

上述检查只能依据观众可感知的对白、动作和视听信息。纯剧本测试可以据此给出候选排序与暂定结论，但必须注明证据来自剧本预计；只有真实 ASR 和视频核实后才能标记为最终通过。

任一项不满足，就向前扩展一个自然叙事单元并重新检查。扩展不得超出授权集数或收费点；到达范围起点仍不成立时，记录对应的不适用原因，只保留连续版，不循环扩展或捏造前情。若某个较早入口能增加观众实际可感知的必要信息，并持续提供与开头有因果联系的背叛、欲望、危险、反转、身份疑问或权力变化，应保留较长版本。不得因为这些事件各自也能形成钩子就认定它们会分散主线；只有出现重复、长时间无推进或无关旁支时才缩短。禁止通过设置最短或最长秒数代替上述判断。

### 入口比较

覆盖检查与入口资格检查独立：当前候选全部通过顺播检查，只说明它合格，不代表搜索完成。锁定前回看完整事件清单，确认每个更早相关事件均有比较或排除记录。对于比选中入口更早的正式候选，逐个记录 `earlier_prefix_review`：新增信息、刺激或反转、与开头的联系、无推进或旁支成本，以及最终不选它的具体理由。不能用“已经够懂”“更集中”“更短”代替这一检查；也不能默认最长入口必胜。

只有入口资格和候选覆盖都完成才能锁定。结构校验只能发现记录缺失、引用断裂和已登记候选被漏比；执行者仍须把事件清单与完整正文及真实视听证据核对，不能把校验通过当作剧情吸引力或搜索完整性的证明。

选择第二段入口前，先列出可行入口，并逐一记录它建立了什么、缺失什么、包含哪些强事件、中间是否存在平淡或重复区间、是否形成情绪投入，以及回到开头时的效果。对较早入口额外执行“新增前缀价值检查”：新增内容是否提供新的观众信息、强刺激、反转或关系变化，是否与开头因果相连，是否没有明显无推进区间。三项都成立时，不得仅因它更长或包含多个强事件而删除。最终理由必须说明为什么被选入口比其他入口更值得连续观看；不得用“离开头最近”“更集中”或“信息已经够懂”作为唯一理由。

出现以下任一情况时，当前入口必须向前扩展并重新比较：

- 第二段像剧情摘要或解释补丁。
- 主要内容只是人物说明身份或交代事实。
- 播放不久就重新撞回开头。
- 观众能够理解，但尚未来得及投入人物、冲突或欲望。
- 回到开头时只有信息闭环，没有情绪或行动上的兑现。
- 结构虽然完整，但缺少持续吸引人的具体事件，或者关键身份、关系与处境信息仍然单薄。

### 追上、回声与恢复

回接内容完整顺播到 `opening_window.start` 后，跳到冷开结尾的 `opening_echo`，只重复一次冷开的最后一句完整台词或最后一个完整动作，再从 `opening_window.end` 之后的完整动作或台词接入新剧情。`opening_echo` 必须是 `opening_window` 末尾的连续子区间，终点与 `opening_window.end` 完全一致；在 `echo_type` 中记录 `last_line` 或 `last_action`，并在 `echo_content` 中写明实际重复内容。选择台词还是动作，以哪一个更能让观众确认“已经追上”且连接更自然为准；不得同时重复多轮问答、整场反应或整个冷开。回声起点和新剧情恢复点都必须用视频检查，避免半句、口型截断、门把手、抬手、接触等动作瞬间跳坏。

恢复后继续顺播，不以约 `150` 秒为机械停点。先让开头中的爆点完成或产生明确后果，再停在随后出现的第一个新悬疑点：新的未知结果、身份或关系疑问、即将发生但尚未完成的关键行动。若所谓悬疑点只是开头原有问题尚未解决，不算新的停点。

### 问题字幕卡与倒放

`reset_transition` 是固定渲染项，顺序为：静止开头末帧 `0.8` 秒、显示 `2.0` 秒黑屏问题字幕卡，再接 `1.0` 秒快速倒放。静帧保持原尺寸和位置，不缩放、不震动；静帧和字幕卡都静音。字幕卡把开头留下的核心未知改写为一到两行短问句，例如 `HOW DID SHE / END UP HERE?`；优先使用当前人物和处境，不用 `Earlier`、`Before that` 等泛化章节提示，也不写前情摘要。

字幕卡采用克制的两级居中排版：第一行较小、第二行突出，可使用一条短暖金色细线建立层级；不添加飞入、震动或复杂动画。两行文字必须在水平安全区内按实际字宽自动缩放，不得裁切。字幕卡必须作为完整媒体段插入：按输出帧率生成的 `2.0` 秒黑色视频和同样持续 `2.0` 秒的真实静音音轨从同一时间点开始并同时结束。

倒放段从紧随字幕卡之后的完整 `reset_context` 取样，把整个前情段压缩为 `1.0` 秒反向播放，并准确落在该段第一帧。倒放原对白静音，使用短倒放音效；末段减速落点，正常前情从第二帧恢复，避免第一帧重复造成停顿。不得只倒放任意几秒，也不得落到前情中间。工具不能生成完整字幕卡、倒放和同步音频时，冷开回接版不得标记为完成。

## 末帧保持

连续版和冷开回接版完成全部剧情区间后，冻结各自最终帧 `1.0` 秒。冻结的是尾钩边界处已经选定的最后一帧，不得为了获得更适合静止的画面擅自改变剧情切点。冻结开始时做一次短促的非对称震动并衰减回原位置，随后稳定保持；不得放大或渐变，也不得在整秒持续抖动。

片尾同步播放 `1.0` 秒鼓点或撞击尾音。优先检查承载当前结尾的原剧集文件最后 `1.0` 秒；只有确认该区间不含对白或其他人声、且不与紧邻剧情尾部重叠时，才按原速、原音量、未经淡入淡出处理的方式使用。若不合格，可改用其他已确认的原剧鼓点；仍无合格音效时静音回退。不能把刚播过的最后一句或最后一个动作的声音重复一次。片尾计入实际输出时长但不计入源视频 `ranges`；在 `end_hold` 中记录合格音效的来源、精确起止时间及两项检查结果，或记录 `silence`。

## 上下文检查

无论是否生成冷开回接版，都要记录开头自身的理解缺口：

- `none`：开头窗口已提供必要事实。
- `title_resolvable`：只缺人物关系或轻量背景，可由未来标题解决。
- `video_required`：缺少关键因果，必须靠回接视频解释。

这个字段用于解释字幕需求和冷开回接版可能带来的收益，不直接决定可行性；可行性仍按前述五项检查。

## 尾钩

两版分别在目标时长附近寻找尾钩，允许不同：

- 关键结果即将出现。
- 身份、秘密或关系即将揭晓。
- 暧昧、亲密、性动作或暴力动作即将发生。
- 一句强要求之后的人物震惊反应。
- 一个局部事件结束后，新问题刚刚建立。

时长服从尾钩。不能为了凑到 150 秒停在半句话或无法辨认的中间动作。

## 对比报告

只描述事实：

- 冷开回接可行性五项检查及最终结果；不成立时写明原因码和证据。
- 冷开回接版存在时，说明它补充了哪些信息、花费多少时长。
- 冷开回接版存在时，说明比较了哪些自然入口，最终入口为何提供更充分的观众信息、强事件推进、情绪积累和回接效果；若选择较长入口，说明新增前缀如何持续贡献价值。
- 每版推进到了哪个剧情位置。
- 每版尾钩是什么。
- 哪些连接点明显、哪些黑场需要清理。

可以给出规划建议，但不得用版本数量反向修改三个已锁定开头。三个连续版始终保留；每个通过可行性判断的冷开回接版各增加一条，最终共 3 至 6 条供人观看选择。
