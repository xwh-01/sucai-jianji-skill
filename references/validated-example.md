# 已验证案例：EP3 假叫床

这个案例用于说明工作流，不是所有剧的固定模板。

注意：本案例及配套 `validated-example.json` 是历史记录，没有保存新版要求的全范围前情搜索记录，不能作为新版最终计划的合格样例，也不能据此认定 EP3 就是最佳回接入口。重新执行时必须先检查授权范围内更早正文，补充真实的 `entry_search`、候选引用和前缀比较；本次流程更新没有重新审片，不补造这些证据。

新版结构回归示例见 `scripts/test_validate_edit_plan.py`：使用明确的合成事件测试关系建立、冲突起源、直接触发三个层次。测试允许选择更早入口，也允许在记录具体前缀代价后选择更晚入口；不把本例或任何历史候选写成固定答案。

## 开头窗口

```text
EP3 00:26.50-00:47.14
```

内容：亚瑟发出露骨假叫床声音，门外人物认出他，凯西质问，亚瑟要求她配合，凯西承认自己从未叫过床。

它同时包含第一刺激和第二揭示，并在窗口内部重新提供了当前事件的必要事实，因此 `context_gap = none`。

系统先锁定两版全部剧情区间，再生成唯一一组三行头顶字幕，不要求人工选稿，也不允许字幕反向改变选段。本例的台词与画面已经足够理解，因此字幕采用 `retention_hook`，承诺后续欲望升级。两版共享同一文案和自动视觉设计：抽查开头前 4.0 秒代表帧后选定高对比基础色和强调色；字幕无矩形底框，完整显示 3.0 秒并在随后 1.0 秒淡出。

## 连续版

```text
EP3 00:26.50-02:04.56
-> EP4 00:00.00-00:54.30
```

剧情区间约 152.4 秒，加入 1.0 秒末帧短震动和原剧鼓点后实际输出约 153.4 秒。内容从假叫床推进到赶走女配、性爱教学契约和掌心吻。尾钩是亲密动作已经开始但尚未完成。

## 冷开回接版

```text
开头：EP3 00:26.50-00:47.14
-> 0.8 秒静止开头末帧
-> 2.0 秒黑屏问题字幕卡：HOW DID SHE / END UP HERE?
-> 1.0 秒快速倒放完整前情段，落回 EP3 00:00.00
-> 回接：EP3 00:00.00-00:26.50
-> 重复冷开最后一个动作：EP3 00:43.80-00:47.14
-> 恢复：EP3 00:47.14-02:04.56
-> 延续：EP4 00:00.00-00:25.50
```

剧情区间约 153.4 秒，加入静帧、字幕卡、倒放和 1.0 秒末帧短震动及原剧鼓点后实际输出约 158.2 秒。系统先把开头留下的问题反推为“受辱动机 -> 临时合作关系 -> 亚瑟提出假演”的必要因果链，再把最晚完整入口与更早的场景入口顺播比较。最晚入口虽然能够解释动作，却缺少冲突建立和情绪积累；因此回接选择 EP3 场景起点，而不是只取开头前几句解释。倒放覆盖整个前情段并落回其第一帧，正常回接从第二帧恢复。前情追上后只重复冷开的最后一个完整动作，以此确认已回到当前时点，再接入新剧情；假演爆点兑现后，停在新的亲密教学要求形成的悬疑点。

## 已观察到的差异

- 连续版推进更远，信息效率更高。
- 冷开回接版因补充 26.5 秒前因，只推进到第一课开端。
- 冷开回接结构可理解，但观众能感知“开头 -> 回溯”和“追上 -> 恢复”两次结构切口。
- 两版都成立，因此初版固定保留两条，不让模型提前替用户取消某一版。
- 两版开头标题固定显示 3.0 秒并用 1.0 秒淡出。
- 冷开回接版在回接前固定插入 0.8 秒静帧、2.0 秒黑屏问题字幕卡和 1.0 秒完整前情倒放；两版结尾都固定冻结末帧。
- EP3 到 EP4 的源片存在短黑场，精剪时应清理，但不影响粗剪工作流成立。

## 历史方法结论（执行以新版流程为准）

开头来自较后集数，不等于必须返回第一集。冷开回接版先从开头留下的核心问题反推直接原因、人物动机和必要关系背景，把必要因果链作为理解门槛；再比较多个自然入口，选择连续剧情弧、情绪积累和回接体验最好的一条。不能仅按“还缺哪条事实”把第二段压缩成几秒解释片段，也不能默认偏向最晚入口或用固定秒数代替顺播判断。爆点兑现后，在第一个新的具体悬疑点结束。即使开头已经自解释，也可以生成冷开回接版作为不同节奏方案，但必须在报告中说明它增加的信息和消耗的时长。
