# 开头选择

## 目标

从用户允许范围内的完整剧本中找出多个可映射到真实视频的开头候选，锁定其中 3 个；每个开头始终生成连续版，并在开头锁定后独立判断是否生成冷开回接版。

## 四种主要机制

每个候选只记录一个最主要类型，分类不是配额。

- `strong_dialogue`：露骨、冒犯、反常、羞辱、揭密、威胁或直接改变关系的台词。
- `strong_stimulus`：性暗示、暴力、强身体动作、尖叫、呻吟、撞击或视觉异常。
- `strong_event`：陌生观众能快速看懂“谁对谁做了什么”的冲突事件。
- `strong_suspense`：观众知道自己正在等待哪个答案或结果，而不是单纯看不懂。

## 硬门槛

候选必须包含具体可听或可见的停划点。`高能`、`张力爆表`、`视觉锤` 等作者标签不能作为证据。

允许开头只是噱头：

- 不要求后文解释全部内容。
- 不要求来自第一集。
- 不要求与广告正文直接相连。
- 剧情相关性只能作为审阅信息，不能作为硬淘汰条件。

## 发现方法

阅读完整分场正文，对每个场景检查：

- 最露骨或反常的实际台词。
- 最大声的台词或声音是否包含具体内容。
- 最清楚的性暗示、暴力、身体动作或异常画面。
- 关系破裂、证据曝光、身份改变或权力逆转。
- 答案或动作即将发生的明确悬念。
- 声音与画面之间的误导、反差或二次揭示。

第一遍高召回。第二遍合并同一事件的重叠候选，不能让同一段靠不同标签重复占位。最终三条开头必须来自不同事件窗口，不能只是同一段的不同起止版本。

## 候选比较

不要打数值分。按以下顺序直接比较：

1. 第一秒是否出现具体刺激。
2. 陌生观众是否理解刺激的基本含义。
3. 窗口内是否还有第二次变化、揭示或升级。
4. 是否具有本剧独特关系，而不是通用争吵或通用暧昧。
5. 是否能找到完整、可验证的进入和结束边界。

声音型开头优先检查“双钩”：强声音让人停下，画面或反应随后改变观众理解。例如露骨呻吟后揭示其实是在演戏。

## 三层边界

- `hook_anchor`：最强台词、动作或事件成立的瞬间，可以位于剧情块中间。
- `opening_window`：从锚点进入后，使刺激、揭示和反应成立的最短范围。
- `segment_extension`：从窗口继续延伸到自然出口或尾钩的连续视频范围。

文字先给近似边界，ASR 再映射台词时间，真实视频最终确认动作和画面。不要用场次起止代替准确窗口。

## 开头起点确定

锁定 `hook_anchor` 后，按以下步骤确定 `opening_window.start`：

1. 从锚点向前寻找候选起点：完整台词开始、动作启动、人物反应开始或镜头自然切换。
2. 用 ASR 检查是否从半句话进入，用真实视频检查是否从动作或表情的异常中间态进入。
3. 淘汰第一秒没有具体刺激、需要等待铺垫才成立或包含无效前情的起点。
4. 只保留理解当前噱头所必需的内容；不为了交代完整剧情继续向前扩展。
5. 在剩余候选中选择最晚的自然起点，即“仍能让第一秒噱头成立的最短自然入口”。

## 开头止点确定

锁定 `hook_anchor` 后，按以下步骤确定 `opening_window.end`：

1. 从锚点向后寻找候选止点：完整台词结束、动作完成、必要反应落地或镜头自然切换。
2. 用 ASR 检查是否吞字，用真实视频检查是否切在动作或表情的异常中间态。
3. 淘汰台词未完、动作未完、刺激尚未产生结果或必要反应尚未出现的止点。
4. 若紧邻内容存在能明显增强噱头的第二次揭示、反转或升级，继续保留到该变化成立；不要延伸到无关的新剧情。
5. 在剩余候选中选择最早的自然止点，即“噱头完整成立后的第一个自然切点”。

止点同时服务于两版；在冷开回接版中，它决定黑屏插入位置、冷开结尾回声的终点，以及重复最后一句或最后一个动作后从哪里接入新剧情。记录所选止点及其成立依据。

## 候选输出字段

每条至少包含：

```json
{
  "id": "opening-001",
  "primary_type": "strong_stimulus",
  "episode": 3,
  "script_anchor": "实际台词或动作",
  "gimmick": "陌生观众会被什么抓住",
  "first_hook": "第一秒刺激",
  "second_hook": "后续揭示、反应或升级",
  "opening_window": {
    "start": 26.5,
    "end": 47.14
  },
  "video_checks": ["需要在真实视频确认的事项"]
}
```
