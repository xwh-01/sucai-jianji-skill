# 切口精修

## 目标

把剧本和 ASR 给出的近似时间收敛到真实视频中的具体帧，使台词、动作、表情和声音自然落稳，同时避免用大范围逐帧分析增加不必要成本。精修只调整边界，不得改变已经锁定的开头、剧情路径、冷开回接入口或尾钩。

最自然的切点不是固定意义上的静音点或镜头切换点，而是满足剧情语义后，声音、动作和画面最早共同稳定的帧。

## 处理单位

每个切口都必须记录：

- `approx_time`：剧本或 ASR 映射出的近似秒数。
- `legal_interval`：不破坏剧情语义的允许移动区间。
- `candidate_points`：允许区间内最多三个有效候选。
- `selected_time` 与 `selected_frame`：最终采用的源视频秒数和帧号。
- `cut_role`：切口用途。
- `selection_reason`：为什么该帧比其他候选自然。
- `confidence`：`high`、`medium` 或 `low`。
- `checks`：台词、声音、动作、表情、字幕和技术边界检查。

开始点和结束点必须分别精修。两个片段的连接质量必须按一对切口检查，不能只证明各自单独成立。

## 搜索范围与成本控制

- 普通剧情切口默认只检查 `approx_time` 前后各 `1.0` 秒。
- 清理源片片头、片尾、黑场、定版字或编码填充时，可检查前后各 `2.0` 秒。
- 先用 ASR、声音活动、镜头变化和运动变化缩减候选，再查看候选附近帧；不要对整集逐帧计算。
- 每个切口最多保留三个候选：语义最佳点、邻近自然镜头边界、声音与运动共同低点。明显失败的点不进入候选集。
- 只有候选信号冲突或 `confidence` 不为 `high` 时才生成微预览。高置信度切口直接锁定。
- 默认范围内没有合法候选时，回到剧情结构层把边界扩展到相邻的一个完整台词、动作或反应单元；不得只为找到低运动帧任意扩大搜索。

## 精修顺序

### 1. 划定语义合法区间

先根据 ASR 和真实视频写清楚该切口前必须兑现什么、后面必须保留什么：

- 开始点必须位于理解当前动作或台词所需的信息之前。
- 结束点必须位于当前台词、动作结果或必要反应成立之后。
- 新剧情、无关停顿、下一轮问答或技术片头片尾不得因精修被带入。

语义合法区间是硬约束。任何位于区间之外的声音低点或镜头切换都不能入选。

### 2. 生成候选

只在合法区间内寻找：

- ASR 单词或句子边界，以及人声活动开始和结束点。
- 硬切、叠化完成点或新镜头稳定后的第一帧。
- 动作启动前与动作完成后的局部运动低点。
- 表情反应已经可辨认、但下一动作尚未开始的帧。
- 烧录字幕完整出现或完整消失的边界。
- 黑场、重复帧、长静帧、片头字和片尾定版的技术边界。

不要直接把检测结果当作最终切点。镜头检测、音量和运动量只负责提出候选，真实台词、画面和连接预览负责最终确认。

### 3. 硬淘汰

候选出现下列任一情况即淘汰：

- 截断单词、呼吸、笑声、哭声、撞击声、门声或对剧情有意义的声音尾部。
- 人物仍在清晰说话，嘴型与声音会被突然切断。
- 手势、转身、起身、坐下、开门、接触或视线转移处于不可理解的中间态。
- 台词后的关键表情反应刚开始但尚未成立。
- 烧录字幕只出现一部分，或上一句字幕无意义地残留在新段开头。
- 位于闪白、叠化中段、剧烈运动模糊、曝光跳变或编码坏帧。
- 片尾停在黑场、定版字、技术性重复帧或无剧情意义的静帧。
- 作为 `0.8` 秒冻结帧时会明显呈现半眨眼、半张嘴或动作卡住。

### 4. 按用途选帧

#### 开头起点

- 第一秒必须出现明确的可听或可见刺激。
- 台词先发生时，从第一个清晰音节前约 `80-120ms` 进入，保留必要起音，不保留无信息等待。
- 动作先发生时，从动作启动前 `2-4` 帧进入，使观众看得到动作发起而不是突然处于动作中段。
- 镜头切换发生在刺激前时，优先从新镜头第一帧进入；若第一帧仍在叠化或曝光恢复中，则从第一个稳定帧进入。

#### 普通剧情起点

- 从完整问答、行动或反应单元的自然入口进入。
- 若开场人物已经处于动作中段，向前移动到动作启动；不能只因 ASR 首词对齐就从半个动作开始。
- 若上一句声音自然跨入当前镜头且属于当前剧情，保留它；不要为了画面整齐硬切声音。

#### 开头终点与冷开冻结帧

- 刺激、揭示和第一层有效反应必须全部成立。
- 在反应成立后的第一个运动低点结束，并确保该帧静止 `0.8` 秒仍像有意停顿。
- 下一轮新问答或新动作已经开始时应向前收，不把新叙事单元带进开头。
- 冻结适配性只能在语义合法区间内决定具体帧，不能为了找漂亮静帧缩短爆点或删除必要反应。

#### 普通段落终点

- 保留完整可理解的最后一句，并让句尾声音自然衰减。
- 句尾后通常只需保留约 `120-300ms`；若关键反应尚未成立，则延长到反应完成，不能机械套用时长。
- 在当前动作结果成立后、下一动作启动前结束。
- 尾钩必须先形成具体期待，再切断答案；不能在问题尚未建立时提前结束。

#### 追上点、冷开结尾回声与恢复点

- 前情顺播必须完整追到 `opening_window.start`，不能提前跳走。
- `opening_echo` 从冷开最后一句完整台词或最后一个完整动作的自然起点开始，并与 `opening_window.end` 同时结束；不得从半句、半个动作开始，也不得扩展成整个冷开窗口。
- 恢复点位于 `opening_window.end` 之后的第一个完整台词或动作入口。
- 检查从前情到回声、再从回声到新剧情时的人物姿势、手中物体、门的位置、接触动作、口型和视线方向，避免动作瞬移或声音跳变。
- 若恢复点正处于原开头末尾动作的延续，向后移动到该动作结束后的自然入口，而不是插入转场掩盖问题。

#### 跨集片头与片尾

- 片尾从后向前排除黑场、定版字、平台标识、编码填充和技术性重复帧，只保留最后一个完整剧情反应及其声音。
- 片头向后排除黑场、平台标识、上集重复和无意义静默，从第一个完整可辨认的剧情画面或有效声音前进入。
- 相邻两集若重复同一段内容，以语义和动作连续为准只保留一份；在重复段开始前和结束后分别找稳定对应帧，不得留下重复台词或漏掉新内容。
- 跨集不是天然切点。片尾剧情与下一集新内容本来连续时，必须把两侧作为一个连接共同检查。

#### 最终冻结末帧

- 先按尾钩语义确定允许结束范围，再在其中选择最后一个自然稳定帧。
- 排除半眨眼、半张嘴、动作中段、运动模糊和技术尾帧。
- 片尾预览必须保持构图和尺寸不变，只在开始时做一次短促衰减震动并回到原位置。鼓点或撞击音效优先参考当前结尾所在原剧集文件最后 `1.0` 秒，并确认不含人声且不与紧邻剧情尾部重叠；无合格音效时静音回退。

### 5. 用固定优先级决策

不使用不透明的综合分数。候选按以下顺序比较：

1. 剧情语义和观众理解完整。
2. 台词及有意义的声音没有被截断。
3. 动作和表情已经成立，没有卡在中间态。
4. 画面处于稳定、清晰且字幕完整的状态。
5. 在前四项相同时，选择无效停顿更短、进入有效信息更快的点。

镜头切换只是一种候选，不享有默认优先级。不能为了落在漂亮的镜头边界上吞掉台词，也不能为了找到绝对静音保留冗长停顿。

## 连接检查

对非连续片段，拼出切口前 `1.5` 秒和切口后 `1.5` 秒再判断：

- 前段声音是否自然结束，后段声音是否从完整起音开始。
- 背景音乐、环境声或混响是否发生无法解释的突断。
- 人物位置、动作方向、道具状态和视线是否造成明显跳变。
- 新段是否立即提供可理解的信息，还是出现一段无意义等待。
- 若两段本来来自同一视频且时间连续，合并源区间，不制造人为切口。

默认使用硬切。若连接不自然，先重新选择两侧边界；不得优先用叠化、音频淡化或其他转场遮盖错误切点。

## 微预览与置信度

- `high`：语义、声音、动作和画面指向同一候选，直接锁定。
- `medium`：存在两个合法候选，或镜头边界与声音边界不一致。为最多三个候选生成约 `3.0` 秒连接预览后选择。
- `low`：所有候选都存在台词、动作或连续性问题。不得硬选；向相邻一个完整叙事单元扩展后重新精修。

`low` 只能保留为失败尝试，不能作为最终通过状态。`medium` 须实际查看预览并记录通过依据后才能锁定。扩展越过合法语义范围时返回主流程第 4 阶段复核路径；不得自动重选开头。相邻单元仍无法解决时记录未完成切口，不无限扩大搜索。这里规定的是执行方法，目前没有独立候选生成脚本；不得把填写置信度当作已经完成视听核查。

需要预览时，输出到 `boundary-review/`：

- `start-<cut-id>-a.mp4` 等开始点预览。
- `end-<cut-id>-a.mp4` 等结束点预览。
- `join-<cut-id>-a.mp4` 等前后段连接预览。
- 冻结相关切口额外生成包含完整 `0.8` 秒静止的预览。

## 记录格式

每个开头目录保存 `boundary-review/boundary-refinement.json`。最小结构：

```json
{
  "cuts": [
    {
      "cut_id": "opening-end",
      "cut_role": "opening_end_freeze",
      "source_video": "/absolute/path/EP03.mp4",
      "source_fps": 30,
      "approx_time": 47.1,
      "legal_interval": { "start": 46.6, "end": 47.7 },
      "selected_time": 47.133,
      "selected_frame": 1414,
      "confidence": "high",
      "selection_reason": "揭示和人物反应均已成立，下一动作尚未开始，静止 0.8 秒无中间态。",
      "checks": {
        "speech_complete": true,
        "meaningful_audio_complete": true,
        "action_complete": true,
        "reaction_complete": true,
        "subtitle_complete": true,
        "stable_visual": true,
        "freeze_safe": true
      },
      "candidate_points": [
        {
          "time": 47.133,
          "frame": 1414,
          "kind": "reaction_settled",
          "selected": true
        }
      ],
      "preview_files": []
    }
  ]
}
```

帧号从 0 开始，逐源文件记录帧率；可变帧率素材以实际帧时间戳为准，帧号不能由平均帧率乘秒数推算。区间采用 `[start, end)`：起点包含，终点不包含。结束切口的 `selected_time` 指排他终点，`selected_frame` 指该边界后首个被排除的源帧；冻结图必须取终点之前最后一个实际保留帧，另记录其时间与帧号。到达文件末尾时记录文件时长及总帧数作为终点。最终裁剪应重新编码或使用支持精确时间的流程，不能为了速度强制吸附到关键帧而改变已锁定切点。

## 完成条件

- 每个实际裁剪边界都有源时间和具体帧依据。
- 没有半句、声音尾部截断、动作中间态或未成立的关键反应。
- 开头起点快速进入刺激，开头终点可自然冻结。
- 冷开追上后只完整重复最后一句或最后一个动作一次；没有整段开头重播、动作瞬移或口型错位。
- 跨集连接已清除技术片头片尾和重复剧情，但未删除新内容。
- 高置信度切口没有多余候选预览；中置信度切口有已检查的预览与通过依据；低置信度失败尝试保留记录，但不作为最终已通过切口。
